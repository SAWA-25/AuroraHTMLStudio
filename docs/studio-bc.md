# 创作起始台 B+C 界面修订

本次把 Aurora 的入口改为真实 HTML 创作起始台，以当前作品、代码摘录与画布衔接贯穿开场和工作台。原生项目、编辑器、助手和工具处理器继续负责业务数据。

首页移除生活、贴贴、一起听及固定示例文字；支持当前作品、最近项目、原生模板、项目档案、工具、设置和助手。昼夜设置与原生应用同步。开场使用代码形成预览框，作品预览与工作台画布双向衔接；不支持 View Transitions 或减少动态效果时直接切换。

## 适用范围

本仓库根目录 `dist/` 仅收录此次修订必需的四个界面资源与说明文件，是已有 7.7.0 安装的局部改动，不是完整安装包。请勿把整个目录覆盖到未知版本，也不要覆盖 data、st、浏览器配置、快捷方式或启动器。当前版本号保持 7.7.0，以 Git commit 和哈希清单区分本次修订。

前端源码仍可在 `frontend/` 内执行 `npm ci`、`npm test`、`npm run build`。原生业务文件与 C# 启动器不在此源码仓库；构建只生成呈现层资源，单独运行不构成完整 Aurora。

## 验证

前端回归 40/40 通过，构建成功。临时 Launcher 与独立 Chrome 中定向验证 1440×900、390×844、原生入口、主题同步、双向画布转场、减少动态效果、焦点恢复及静态预览隔离。首页预览不执行用户脚本、不请求外部资源；完整交互、外部资源和受限 Canvas 需进入工作台。

这些结果是本次改动的定向验证，不代表全部工具和正式发布门禁已完成，也没有发布新的自动更新 Release。程序资源的精确 SHA-256 见 `studio-bc-revision.json`。
